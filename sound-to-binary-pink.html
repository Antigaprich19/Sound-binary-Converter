🎀 Explain It

1. In your own words, how does your app change a sound wave into binary? Name the three steps.
First it samples the wave by measuring its height at equal time steps. Then it rounds each height to the nearest level, and finally it writes each level in binary using the chosen number of bits.

2. Run Test A again with 2 bits, then 6 bits. Which gives more detail about the wave, and why?

3. Which test has the longest wavelength? How is wavelength connected to frequency?
Test B has the longest wavelength because it has the lowest frequency (200 Hz). Wavelength = 343 ÷ frequency, so a higher frequency means a shorter wavelength.

4. What was the hardest stage to build, and how did you fix it?
The hardest stage was the warnings, because empty fields turned into 0 and passed as valid numbers. I fixed it by checking for blank values first, then checking each range one by one so every bad input shows a clear message.

Extra: How does the Upload Audio tab work?
The browser decodes the file into numbers between -1 and 1, mixes the channels into one, and picks evenly spaced samples across the whole clip. Those samples go through the same rounding and binary steps as the tone.
